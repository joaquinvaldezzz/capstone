## Findings considered and rejected

- **SSRF in Next.js rewrites**: Flagged during initial automated pass because `next.config.js` proxies `/flask-api/:path*` to `http://127.0.0.1:5000/api/:path*`. Rejected because forwarding API calls to a local Flask service is standard architectural design for this project, not an SSRF vulnerability.
- **Immediate migration to Tailwind v4 theme variables**: Considered during dependency audit; rejected from initial plans to avoid unnecessary styling churn while core security, correctness, and verification baselines are being established.
- **Automated Random Ground Truth generation**: Found in `index.py:188` during initial audit; rejected and eliminated in Plan 004 because synthetic/random ground truth in runtime diagnostic systems is clinically unacceptable.
